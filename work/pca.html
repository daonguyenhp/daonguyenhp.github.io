04 · Products and applied ML

PCA faces

Take a face from the webcam, find it with OpenCV, and recognize it with PCA written in the project.

Field Products and applied ML
Role Team project. The README lists Nguyễn Đăng Gia Đạo as author 1.
When 2 Jun 2025
Stack Python, OpenCV Haar cascade, PCA, Tkinter
Code github.com/daonguyenhp/mt1007_pca

Context

A face demo often calls a finished recognizer. This one builds the eigenfaces in the project, so the method is visible.

What it does

  • Tkinter takes the photo from the webcam.
  • OpenCV Haar finds the face.
  • PCA, written in the project, does the recognition.

What is true

This is team work. There is no accuracy number on this page, and it does not wrap a ready-made face API.
