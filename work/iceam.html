04 · Products and applied ML

ICEAM

A chatbot for a small shop. Stock lives in Excel. Answers come from a model called through OpenRouter.

Field Products and applied ML
Role Team project for a faculty course. This page does not split the files by person.
When May 2025
Stack Node.js, Excel knowledge base, OpenRouter, DeepSeek
Code github.com/daonguyenhp/xinloividaden

Context

A shop assistant that only chats is not useful if it cannot see what is in stock. The project keeps the stock in a spreadsheet and lets the model answer from that file.

What it does

  • Node.js reads the stock from Excel.
  • Questions go to a model through OpenRouter.
  • The write-up is a course report in the computer science faculty, May 2025.

What is true

This is team work. The course report is from May 2025. The GitHub repo was created in Jan 2026. There is no shop count, no accuracy number, and no claim that a store is using it.
