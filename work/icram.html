Context

A focus timer is a small product with an account, a clock, and something to listen to. It is not an agent and not a hardware project.

What it does

  • Pomodoro and a stopwatch.
  • Music played in the page.
  • Sign-in with a session, and records stored in MongoDB.

What is true

The app runs when a server is running. There is no public deployment and no user count.

https://daonguyenhp.github.io/icram-web/ serves the repository page. It is not the running timer.
