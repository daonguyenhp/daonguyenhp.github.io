Multimodal Sarcasm Detection on Edge Devices

  • AI
  • Robot
  • Software

Dual-branch Vietnamese multimodal sarcasm classifier (hybrid FastText text encoder + MobileNetV2 image encoder) trained on ViMMSD, quantized to INT8, and deployed on an ESP32-S3 board with TensorFlow Lite Micro.

View source on GitHub
Field AI research and computer vision
Task & Data 4-class multimodal sarcasm classification on ViMMSD (10,805 Vietnamese text + image posts)
Hardware ESP32-S3 N16R8 (16 MB Flash, 8 MB Octal PSRAM) · ~1.39 s / sample on-device latency
Stack PyTorch, Keras / TensorFlow, INT8 TFLite Micro, ESP-IDF, ESP-NN, FastText, MobileNetV2
Code github.com/daonguyenhp/edge-ai-sarcasm

End-to-end edge pipeline

01 · Dual-branch fusion

Fuses 128-D Vietnamese text features and 512-D MobileNetV2 visual features into a 4-class MLP classifier (not-sarcasm, text-sarcasm, image-sarcasm, multi-sarcasm).

02 · PyTorch ↔ Keras parity

Transfers trained PyTorch weights to Keras with verified numerical equivalence (max absolute logit difference within 1e-6).

03 · Post-training INT8 quantization

Calibrates and quantizes the fused model into an ~7 MB INT8 model_int8.tflite binary tailored for custom 8 MB factory flash partitions.

04 · ESP32-S3 TFLite Micro execution

Runs on-device inference on ESP32-S3 (16 MB Flash / 8 MB Octal PSRAM) with ESP-NN acceleration at ~1.39 s per multimodal sample.
