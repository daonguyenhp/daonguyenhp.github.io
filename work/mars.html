MARS Modular

Modular C++17 & ROS 2 navigation stack for autonomous robots with limited vision range to detect and escape blind-alley regions.

View source on GitHub
Field Embodied AI and robotics
Role Implemented the 4-module C++17 navigation pipeline and ROS 1 / ROS 2 simulation runners
Stack C++17, ROS 2, ROS 1 Noetic, CMake, Gazebo, RViz, Python
Code github.com/daonguyenhp/MARS_Modular

4-module architecture

01 · Perception geometry

Extracts closed/open sights, neighbor sights, and candidate open points from limited-range LiDAR scans.

02 · Graph & bundle memory

Updates the visibility graph, sequences of line-segment bundles, and ranking memory across steps.

03 · Navigation decision

Selects forward targets, detects dead-end traps, and computes collision-free escape angles via DAP funnel.

04 · ROS 1 & ROS 2 simulation

Runs Mode 1 C++ benchmarks, SVG trajectory plots, and full Gazebo / RViz robot simulations.
