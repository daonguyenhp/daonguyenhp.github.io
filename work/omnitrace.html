OmniTrace

Drop in the trace of a run that just failed. OmniTrace finds the smallest piece that still fails, then opens a new thread with that piece removed.

Context

When an agent fails, the error span is often not the real cause. You need the step timeline, a way to cut the bad context down, and a clean thread to continue from.

Approach

Load one failed run as OpenTelemetry GenAI JSON. Isolate finds the smallest piece that still fails. Fork starts a new thread with that piece removed. Inspect is optional and off on the free Render demo. CLI covers Isolate and Fork too.

What is true

Public repo and live demo at omnitrace.onrender.com: drop a file or open a sample, then run Isolate and Fork. Trace stays on that machine. Hosted on Render because it is a Docker app, not a static page.

Free Render sleeps when idle — first open can take 30–60 seconds. Tutorial video is still a placeholder.
